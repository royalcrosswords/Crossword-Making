# Third-party notices

## Dictionary data in `default.txt`

The bundled `default.txt` is a combined word list. It is data only; the crossing-aware solver and editor are original Gridwright code. Notices for the separate `.puz` writer adaptation and bundled PDF libraries appear below.

### Public-domain common-word set

The first common-word entries are derived from `5000-more-common.txt` in Michael Wehar's [Public-Domain-Word-Lists](https://github.com/MichaelWehar/Public-Domain-Word-Lists) repository. The repository README says this list was generated by Michael Wehar, is released into the public domain, and utilized OPTED. The order is preserved as supplied; it is not treated as a precise frequency ranking.

### SCOWL-derived entries

Additional entries are derived from the default English list distributed by [neopass/wordlist](https://github.com/neopass/wordlist), which describes its approximately 86,000-word default list as assembled from sources including SCOWL. The bundled words are filtered to alphabetic entries of 3–15 letters and deduplicated.

## British word-priority list

`src/british-word-priority.js` is a small, curated list of common British spellings and UK vocabulary written for this app. It is tried before the general `default.txt` in British Cryptic mode; it is not a complete British-English dictionary.

## PUZ writer adapted from Phil

`src/export-formats.js` includes a modified implementation of the Across Lite `.puz` header, string-section, and checksum layout from **Phil**, by Keiran King (Copyright 2017). The source is `files.js` in [keiranking/Phil](https://github.com/keiranking/Phil), licensed under the Apache License, Version 2.0. The implementation was adapted for Gridwright's data model, cell/metadata encoding, clue numbering, validation, and warnings. The modified source file includes a change notice. The full Apache 2.0 license is included as `LICENSE-APACHE-2.0-Phil.txt`.
